# Changelog

## 0.3.0 (2026-11-19)

Restructured after user feedback on 0.2.0: about six agent rounds per request, high credit use, the UX agent
running out of turns, 30 minutes for one Figma screen. Diagnosis with evidence: `docs/diagnosis.md`.
Previous configuration: `backup/v0.2.0/`.

### Workflows
- New, directly callable: `/design-team:specs`, `/design-team:audit`, `/design-team:design`.
- `/design-team:design-ticket` is now a router to one of the three. It no longer runs every agent on every ticket.
- `/design-team:apply-to-figma` enters DESIGN with an existing specification. Starting it is not an approval.
- One coordinator instead of two. One brief file, written once. Handoffs are file paths, not pasted text.
- Agent runs per request: SPECS 1, AUDIT 1, DESIGN 2 (was 6 to 7).

### Agents
- `ux-analyst` and `design-qa` can read the scoped Figma nodes. `figma-designer` can build with `use_figma`.
- Models and effort per role: orchestrator `haiku` low, analyst and designer `sonnet` high, QA `sonnet` medium
  (was `inherit` everywhere). `--deep` runs one dispatch on `opus`.
- Write early, explicit budgets, `STATUS: COMPLETE | PARTIAL | BLOCKED`, partial results are delivered.
- Senior design standard in each role: user and business goal, constructive challenge of weak requirements, existing
  patterns first, facts versus assumptions, one reasoned recommendation.

### Quality rubric
- `rubrics/design-quality.md` (25/25/20/20/10), `rubrics/specs-check.md`, `rubrics/audit-check.md`, mirrored in
  `.claude/rubrics/` as the project-override path.
- 0 to 5 ratings with anchors and evidence; pass at 85 with no rating below 3 and no hard blocker.
- `scripts/score.sh` computes totals and verdicts deterministically. Uninspected criteria are `na` and never scored.
- One QA evaluation of the finished design, at most one targeted correction pass, one recheck of the corrected
  nodes. The deliverable is returned before QA and whatever QA says.
- A scorecard closes every workflow.

### Enforcement
- Plugin hooks: Linear read-only, typed approval before any Figma write, read-only roles, agent write scope,
  handoff budget, run ledger. Both write guards fail closed.
- Explicit agent allowlists generated by `scripts/sync-connector-aliases.py`.
- `settings/read-only-guard.json` is now an optional second layer (Figma edits under `ask`).

### Tests and measurement
- `tests/run-static.py`: 76 deterministic checks. `tests/live/run-live.sh`: 11 live scenarios on mock connectors.
- Mock Figma server: nodes, an inaccessible frame, injected failures.
- `tests/analyze-run.py`: turns and tokens per agent, repeated reads, assertions.
- `scripts/analyze-sessions.py`: measures past runs from local Claude Code transcripts.

### Behavior changes to be aware of
- Workflows now write files: `.design-team/<id>/` in the project folder (0.2.0 wrote nothing).
- A specification is no longer followed automatically by a design proposal and QA. Run `design` when you want design.
- Requires Claude Code 2.1.246 or later (partial results from subagents).
